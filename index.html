Sobre Mim

Sou estudante de Engenharia de Software no UNICEPLAC e estou focando minha preparação prática em desenvolvimento back-end. Atualmente, sigo um roteiro estruturado de estudos que abrange desde lógica de programação e Orientação a Objetos com Java até o desenvolvimento de aplicações com Spring Boot, Spring Data JPA, Spring Security e bancos de dados SQL (como MySQL e PostgreSQL). Apesar de estar no início da minha trajetória profissional em TI, tenho me dedicado a aplicar os conhecimentos teóricos em desafios práticos de código. Sou uma pessoa extremamente organizada, comunicativa, proativa e com facilidade para trabalhar em equipe. Estou em busca de uma oportunidade para aplicar minha base técnica em projetos reais, aprender com o time e contribuir para os desafios de desenvolvimento da empresa.
