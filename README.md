# 💻 Portfólio Pessoal

Este é o meu portfólio pessoal, desenvolvido para apresentar um pouco sobre mim, minhas habilidades, meus estudos e minha evolução na área de desenvolvimento de software.

## Sobre o projeto

Este portfólio foi criado para reunir e apresentar:

- Minha trajetória
- Minhas habilidades
- Tecnologias que estou estudando
- Meus projetos
- Minhas formas de contato

## Tecnologias utilizadas

O portfólio foi desenvolvido utilizando:

- `HTML5`
- `CSS3`
- `JavaScript`

O projeto continuará sendo atualizado conforme avanço nos meus estudos e desenvolvo novos projetos.

## Execução Local

```bash
git clone https://github.com/ArthurLago07/Portfolio.git
```

Depois é só abrir o arquivo "index.html" no navegador.

## Estrutura principal

- `index.html`: estrutura da página
- `style.css` : estilos e visual do portfólio
- `script.js` : interações e comportamento da página
